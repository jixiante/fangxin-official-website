## 已确认的差异

- 沿用全站导航、页脚、返回顶部和体验码到期处理，不复制参考中的旧二维码。
- 保留现有小黎自动挥手、身体轻摆和气泡逐字出现；气泡本身固定，不做参考的弹入动画。
- 中文不保留英文装饰标题；英文、俄文翻译正文并共用布局。
- 原小黎 HTML 的 640px 媒体查询有语法错误，已修正。手机端问答条目按标签、内容上下排列，避免长配方挤压；外文长标题允许断词。

- 参考未列出的 Z01、C03 不加入此页，视频文件与其他页面中的入口保留。
- `#examples`、`#example-0/1/2` 保留为问答卡片锚点。
