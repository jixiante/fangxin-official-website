# 业务详情参考

这里保存用户提供的七份中文 HTML 的正文结构和页面专用样式，供构建直接使用。`sources.json` 记录原文件及图片的 SHA-256。请修改这些模板，不要再通过旧的中文目录生成器覆盖它们。

接入时只作以下调整：

- 用户明确要求不恢复英文副标题；保留已确认的全站导航、页脚、小程序弹窗和返回顶部。
- 图片和视频使用对应本地资产；保留原尺寸、裁切、卡片顺序和各页独立断点。
- 保留既有目录和小黎推荐的英文锚点，修正参考 HTML 缺少闭合标签导致的嵌套。
- 将视频播放按钮接为有直接视频地址的渐进增强入口，点击后创建原位播放器；无脚本可直接打开视频，失败可重试。
- 图片增加键盘打开、Escape 关闭和焦点返回；动画完成后释放 transform，避免覆盖卡片悬停效果。

`business-reference.css` 仅隔离本站公共样式的影响。`business-detail.js` 处理筛选、图片弹层、入场和点击播放。七份模板用于中文详情；英文、俄文仍由 `business-pages.mjs` 使用现有译文生成。中医药康养没有提供参考文件，按此前确认沿用拱形首图并统一视频交互。

2026-10-23 验证：在同一个浏览器、同一个视口依次打开原始参考与网站，检查 1440、900、390 像素宽度。首图、卡片、视频、说明和 CTA 的宽高、字号、行高、间距、网格及圆角共 28 组选择器的所有匹配元素未发现差异；参考的英文副标题也按用户要求隐藏后对照。共享导航和页脚不在复制范围。另实际检查筛选、图片键盘操作及各有视频页面的播放入口，完整项目测试通过。未做手机真机或所有浏览器验证。
